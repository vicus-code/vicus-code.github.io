{{- /* Egy tétel címe linkként (Szöveg, Koncertek, Linkek): rámutatva dőlt lesz. A dőlt betű keskenyebb, ezért egy láthatatlan, álló másolat (data-t, ::before) tartja a helyét: a cím nem lesz rövidebb, és alatta semmi nem ugrik feljebb. Bemenet: dict "href" (ha üres, csak a cím áll ott), "html" (a kész cím) és "jel" (ha igaz, a cím végén egy kis ferde nyíl mutatja, hogy link: a koncertlistában, ahol nem minden sor link). A nyíl az utolsó szóval egy tördelhetetlen egységben áll, hogy keskeny képernyőn se kerüljön egyedül új sorba. */ -}} {{- $html := string .html }} {{- if .jel }} {{- $nyil := `` }} {{- with index (findRE `[^\s<>]+$` $html 1) 0 }}{{ $html = printf "%s%s%s" (strings.TrimSuffix . $html) . $nyil }} {{- else }}{{ $html = printf "%s%s" $html $nyil }}{{ end }} {{- end }} {{- with .href }}{{ $html | safeHTML }} {{- else }}{{ .html }}{{ end -}}
